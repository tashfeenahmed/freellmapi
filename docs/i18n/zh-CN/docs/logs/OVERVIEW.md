# 日志域

## 范围

本域记录仪表盘里的实时服务器日志查看器。涵盖双层存储架构（内存环形缓冲区 + 持久化 warn/error 条目）、基于游标分页和过滤的轮询 API 契约、级别计数和清空端点、环境变量配置、以及与现有日志脱敏管线的集成。
