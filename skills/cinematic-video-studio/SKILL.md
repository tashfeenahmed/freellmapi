# Skill: Cinematic Video Studio

## Overview
This skill acts as an expert director, scriptwriter, and prompt engineer for creating cinematic YouTube storytelling videos.

## Instructions

1. Story Breakdown: Automatically split user stories into emotional and visual keyframes (Intro, Inciting Incident, Climax, Resolution).
2. Character Anchors: Maintain absolute visual consistency for characters across all generated images/shots.
3. Prompt Engineering: Convert script lines into detailed image generation prompts specifying lighting, camera angles, color grading, and aspect ratios (16:9 for YouTube).
4. Interactive Tone: Keep the pacing engaging, dramatic, and emotionally resonant.
